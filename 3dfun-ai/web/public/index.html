    PARADIGM 1

    Feed-Forward Triplane Transformers (LRM Architecture)

    Uses Vision Transformers (ViT) to map single 2D image tokens into explicit triplane representations $T_{xy}, T_{xz}, T_{yz} \in \mathbb{R}^{3 \times N \times N \times C}$. Ray samples query a lightweight MLP decoder. Yields ultra-fast generation (<15s) with continuous volumetric radiance.

    ✦ Key Metric: 8–15s Latency · High VRAM Training (Objaverse 800k assets)
    PARADIGM 2

    Multi-View Latent Diffusion & DMTet (Score Distillation)

    Employs image-conditioned 2D diffusion models (Zero-1-to-3, SV3D) to synthesize canonical views at 0°, 90°, 180°, 270°. Surface geometry is extracted via Differentiable Marching Tetrahedra (DMTet) with neural score distillation sampling and high-resolution PBR baking.

    ✦ Key Metric: High Visual Fidelity · 60–120s Compute · Quad Topology Optimization
    PARADIGM 3

    Hybrid Open Core Pipeline (Course 17 Platform)

    Combines foundational relative depth estimation (Depth Anything V2 DINOv2) with deterministic projective camera geometry, Euclidean distance transform $\Phi(x)$, Marching Cubes, and Taubin dual-pass smoothing. Zero cloud dependency, 100% student transparency, and local ONNX runtime.

    ✦ Key Metric: 100% Free & Offline Capable · 8-Stage Tensor Inspection · 4 Student Labs
    PARADIGM 4

    3D Gaussian Splatting Synthesis (3DGS)

    Generates dense explicit 3D Gaussian radiance fields $\mathcal{G}_i = (\mu_i, \Sigma_i, \alpha_i, c_i)$ directly from latent image tokens. Real-time 60 FPS viewport rendering with high-frequency view-dependent specular highlights and non-Lambertian reflections.

    ✦ Key Metric: 20–60s Latency · High Specular Fidelity · Radiance Field Representation
    PARADIGM 5

    Ultra-Fast Feedforward Transformers (SF3D Architecture)

    State-of-the-art feedforward architecture predicts triplane neural representations, UV unwrap coordinates, and material parameters in under 1 second. Bridges high-speed generative synthesis with instant game-engine asset import.

    ✦ Key Metric: 0.5–2s Latency · Triplane + Material Heads · Direct Engine Export

    Custom training lab

    TinyDepth learns from synthetic color and depth pairs. The trainer holds out entire mesh instances so their views never appear in training.

    1. Render reference views. Turn built-in or custom OBJ and GLB meshes into RGB images, depth labels, masks and camera records.
    2. Fit the depth model. Select the checkpoint by validation MAE. Compare it with a training-set median and optionally rerun with SILog alone.
    3. Measure the visible 3D surface. Export the verified ONNX model, back-project held-out depth, then compare the point clouds using Chamfer distance and F-score.

    TinyDepth uses known camera intrinsics and a foreground mask for the point cloud. Studio uses pretrained models to generate full meshes from a single photo.

    Configure a local experiment

    Copy the command into a terminal in the project’s source folder. It prints the stages. Add --run when you want to execute them.

    python -m training.pipeline --device cpu

    Lab guide

    Run a fair comparison

    1. Pick one image. Start with the teapot or use a well-lit photo of one object. Keep the whole outline in frame.
    2. Keep the settings fixed. Use Draft for both runs and keep preview and export options the same. Change only the engine.
    3. Check both meshes. Rotate each result to the same angle. Compare the outline, thin features, and what each engine inferred on the back.
    4. Record what changed. Open the Experiment notebook, select the image, and download the CSV for your notes.

    What the results tell you

    Runtime
    Elapsed time on the machine that ran the job. Preview and export settings can affect it.
    Triangle count
    The number of faces in the mesh. Compare the count alongside the shape you see in the viewer.
    Watertightness
    Whether the mesh passes the closed-surface check. Rotate the model to judge how closely that surface follows the object.

    How to inspect a 3D result

    In Studio, open Compare with photo and move the slider to see the photo and mesh together.

    Check the outline
    Start near the original camera angle. Missing thin parts and filled gaps often start with the foreground mask.
    Separate shape from colour
    Switch to Wireframe or Clay Studio. Texture can make a feature look raised even when the surface underneath is flat.
    Orbit to the back
    Inspect the underside, cavities, and hidden surfaces. A closed mesh can still differ from the object where the photo gives the model little information.

    Mathematical & Algorithmic Foundations

    Every reconstruction stage in 3DFUN AI is grounded in peer-reviewed 3D computer vision and differential geometry principles.

    1. Feed-Forward Triplane Transformer (LRM Architecture)

    f(x) = proj_xy(T_xy, x,y) ⊕ proj_xz(T_xz, x,z) ⊕ proj_yz(T_yz, y,z)
Ĉ(r) = ∫ T(t)·σ(r(t))·c(r(t),d) dt,  T(t) = exp(−∫σ(r(s))ds)

    Orthogonal triplane features queried by bilinear projection and decoded by an MLP into volume density and colour. Feed-forward 8–15s generation on large synthetic 3D corpora.

    2. Multi-View Latent Diffusion & DMTet (Score Distillation)

    ∇_θ L_SDS = E_t,ε[ w(t) (ε̂_φ(z_t; y, t) − ε) · ∂z/∂θ ]
z_t = √(ᾱ_t)·z + √(1−ᾱ_t)·ε  (noisy render latent)

    Differentiable Marching Tetrahedra optimizes per-vertex SDF values via Score Distillation backpropagated from a frozen 2D diffusion prior. High visual fidelity, 45–90s compute.

    3. 3D Gaussian Covariance Splatting (3DGS)

    Σ_i = R(q_i) S(s_i) S(s_i)ᵀ R(q_i)ᵀ
Σ'_i = J W Σ_i Wᵀ Jᵀ   (2D projection)
C = Σ c_i α_i Π_{j<i}(1 − α_j)  (alpha compositing)

    Explicit Gaussian radiance field factored via rotation quaternion and anisotropic scale. Tile-based rasterization at 60 FPS. Non-solid radiance field representation.

    4. Neural Inverse CAD / B-Rep & Eikonal SDF

    L_eikonal = E[(‖∇_x f_ψ(x)‖₂ − 1)²]
L_total = L_photo + λ_n·L_normal + λ_e·L_eikonal

    Implicit occupancy network with joint SfM pose optimization. Eikonal term enforces unit-gradient SDF regularity. Post-processing recovers sharp B-Rep edges for CAD/STEP export.

    5. Volumetric SDF + Marching Cubes (Course 17 Platform)

    Φ(x) = ±min_{y∈∂V} ‖x−y‖  (silhouette-constrained 128³ grid)
p = v_a + (τ−Φ(v_a))/(Φ(v_b)−Φ(v_a)) · (v_b−v_a)
χ = V − E + F = 2  (genus-0 watertight manifold, τ = 0)

    Deterministic: silhouette-constrained SDF → Marching Cubes → Taubin dual-pass smoothing (λ>0, μ<−λ). Result: 100% watertight, Chamfer 0.0639, F@1% 0.148. 100% local ONNX, zero cloud.

    Questions about the lab

    Which images can I upload?

    Studio accepts PNG, JPEG, WebP, and BMP. The upload area shows the size limit. A plain background or transparent PNG makes the outline easier to isolate.

    Which export format should I use?

    Use the included GLB for a single file with geometry and colour. Choose glTF or OBJ when you need separate files, PLY for mesh data, or STL for geometry only. Verify the mesh and set its real-world scale before preparing a print.

    Can I trust the back and dimensions?

    Hidden surfaces are inferred from the photo and can lose holes or fine detail. The exported model uses normalized coordinates. Real dimensions require a known measurement and rescaling.

    What runs on the GPU?

    On Windows, DirectML can accelerate background removal and depth estimation for Depth Anything V2 and MiDaS. TripoSR's encoder and decoder use the CPU in the DirectML build. The Experiment notebook shows which inference providers each run used.

    Where does Gemini chat run?

    Image reconstruction runs locally. The optional chat feature sends messages to Google's Gemini API after you configure a key.
