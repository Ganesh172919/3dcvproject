About the course project

We built this lab to explore what a single image can tell us about 3D shape. Our method removes the background, estimates relative depth, builds a silhouette-constrained volume, then extracts a mesh with marching cubes.

View benchmark results
What makes a good input photo?

Use one clearly framed object, a plain background or a transparent PNG, and a view that shows some of the object's depth.

What can I download?

GLB is included by default. You can also select glTF, OBJ, PLY or STL in the Studio. The mesh estimates hidden surfaces from a single view.

Where does Gemini chat run?

Reconstruction runs locally. Gemini sends chat messages to Google once you add your API key to the project's local configuration.
