Models you can compare

All three run locally and support CPU inference. Use the same teapot photo to see how each method handles its handle, spout, and hidden side.

TripoSR INT8

Predicts a 3D density field from one photo. The lab extracts a mesh from that field and stores colour on its vertices.

Depth Anything V2

Estimates which visible surfaces are nearer to the camera. Our course pipeline turns that depth map and the object outline into a mesh with a texture atlas.

Try Depth Anything with the teapot Depth Anything V2 on GitHub

MiDaS v2.1 Small

Uses the same course pipeline as Depth Anything V2, with a different depth estimator. Compare these two to see how the depth map affects the final shape.

Lab guide

Run a fair comparison

  1. Pick one image. Start with the teapot or use a well-lit photo of one object. Keep the whole outline in frame.
  2. Keep the settings fixed. Use Draft for both runs and keep preview and export options the same. Change only the engine.
  3. Check both meshes. Rotate each result to the same angle. Compare the outline, thin features, and what each engine inferred on the back.
  4. Record what changed. Open the Experiment notebook, select the image, and download the CSV for your notes.

What the results tell you

Runtime
Elapsed time on the machine that ran the job. Preview and export settings can affect it.
Triangle count
The number of faces in the mesh. Compare the count alongside the shape you see in the viewer.
Watertightness
Whether the mesh passes the closed-surface check. Rotate the model to judge how closely that surface follows the object.

Questions about the lab

Which images can I upload?

Studio accepts PNG, JPEG, WebP, and BMP. The upload area shows the size limit. A plain background or transparent PNG makes the outline easier to isolate.

Which export format should I use?

Use the included GLB for a single file with geometry and colour. Choose glTF or OBJ when you need separate files, PLY for mesh data, or STL for geometry only. Verify the mesh and set its real-world scale before preparing a print.

Can I trust the back and dimensions?

Hidden surfaces are inferred from the photo and can lose holes or fine detail. The exported model uses normalized coordinates. Real dimensions require a known measurement and rescaling.

What runs on the GPU?

On Windows, DirectML can accelerate background removal and depth estimation for Depth Anything V2 and MiDaS. TripoSR's encoder and decoder use the CPU in the DirectML build. The Experiment notebook shows which inference providers each run used.

Where does Gemini chat run?

Image reconstruction runs locally. The optional chat feature sends messages to Google's Gemini API after you configure a key.
